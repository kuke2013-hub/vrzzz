# Gloria VR object

Live directory entry: https://kuke2013-hub.github.io/vrzzz/objects/gloria/

This page uses the shared app in `objects/shared/app.js` and imports the unchanged v13 grab engine from `VR_OBJECTS_TEMPLATE/physics-grab.js`. The original Zelda app remains at `/vrzzz/v13.html`.

**Asset required:** Upload the optimized self-contained model as `objects/gloria/assets/gloria.glb`. This binary asset is not present in this commit; the catalogue intentionally reports `pending-model-upload`. Until then, the page offers a local GLB picker rather than pretending the hosted model is available.

Source: user-provided `gloria.zip` containing `source/dgloria.glb`, generated by Tripo. It contained about 1.96 million triangles, 1,006,412 vertices, and three embedded 4096-pixel material textures. Optimized output contains 156,691 triangles, 105,436 vertices, and three embedded 2048-pixel JPEG textures, approximately 4.97 MB. Geometry proportions and material channels are retained. Physical scale is not established by source metadata, so the app uniformly fits the longest dimension to 1.67 m.

No Quest 3 hardware test has been performed.
