Quest controller mapping
Grip: aim the Quest target ray at the object and squeeze to grab nearby or remotely; the second grip joins the hold.
Move: position either held controller UP/DOWN/LEFT/RIGHT; distant manipulation uses both hand displacement and aiming direction.
Twist: wrist rotation controls object orientation, including right-hand pitch and roll in two-hand mode.

Either thumbstick Y: pull object closer or push farther, held or unheld.
Right thumbstick X: rotate held object 30°; without right grip, turn view 30°.
Release: model freezes where placed; zero gravity or momentum.
