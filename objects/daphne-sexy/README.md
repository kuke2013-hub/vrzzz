# Daphne Sexy — Quest 3 VR Object

Permanent URL: https://kuke2013-hub.github.io/vrzzz/objects/daphne-sexy/

Model: original user-supplied self-contained GLB, preserved without mesh or texture changes. The embedded model has one mesh, 291,360 vertices and 466,673 triangles, with 4096×4096 normal, base-colour and metallic-roughness textures. Original GLB: 20,017,088 bytes; SHA-256: 894458111b74dd717dd3f612d76d6c0fdf043794f9ebb39d34c0cc66fbbb42a6.

Its inferred file units are not guaranteed to be physical metres, so the viewer uniformly fits the longest side to 1.67m at load while preserving proportions. The scene uses the shared objects/shared/app.js, the unchanged VR_OBJECTS_TEMPLATE/physics-grab.js Zelda v13 engine, and the model-brightness slider.

The GitHub Actions transfer workflow assembles and verifies the complete binary from temporary transfer chunks and removes the chunks after publishing. Browser/Quest 3 hardware performance has not been validated merely by static inspection.
